# ShopProject — КР №2

Тема: CSS-фреймворки. Автор: Хамидов Дамир Маъруфович, ЭФБО-17-25.

## Практическая №9

Создан отдельный Bootstrap-проект. Главная включает navbar, hero, преимущества, три карточки и подвал. Используются `container`, `row`, `col-12`, `col-md-6`, `col-lg-4`, gutters `g-4` и utility-классы отступов. Bootstrap 5.3.8 CSS и bundle подключены через CDN, затем `css/custom.css`. Изображения — собственные SVG.

## Запуск

Открыть `index.html` или запустить `python3 -m http.server 8001` в папке проекта и открыть http://localhost:8001. Сборка не требуется. В итоговой версии интернет для Bootstrap не нужен: библиотека хранится локально.

## Для защиты №9

Объяснить 12 колонок Bootstrap, разницу container/row/col, переход от одной к двум и трём карточкам, breakpoints md/lg и отступы g-4. Собственный CSS подключён после библиотеки.

Проверка №9 выполнена в браузере на 360, 768, 1440px: сетка перестраивается в 1/2/3 колонки, горизонтального переполнения нет. CSS Bootstrap и custom.css загружаются.

## Практическая №10

Добавлены каталог, описание товаров, заявка и дополнительные контакты. Единая navbar раскрывается на телефоне; card, btn, badge, alert, form-control, form-select, input-group, form-check оформляют содержимое. Bootstrap bundle обеспечивает modal и accordion. `js/main.js` передаёт выбранный товар, проверяет форму и показывает локальный результат. Сервер не нужен.

Для защиты: объяснить data-bs-toggle/target и соответствующий id, различие CSS и JS Bundle, классы формы и `was-validated`. Открыть accordion и модальное окно, проверить Escape, ошибочный e-mail, пустое согласие и корректную заявку. На странице товара показать таблицу и переход к заявке с выбранным товаром.

Проверка №10: мобильное меню раскрывается; карточка товара 2 открывает modal с нужным товаром; пустая заявка отклоняется, корректная показывает сообщение; кнопка закрытия и accordion работают. Локальные ссылки проверены командой `python3 tests/check_site.py`.

## Практическая №11 — итоговая проверка КР №2

Bootstrap 5.3.8 подключён локально: `vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`. Исходник — официальный npm-пакет Bootstrap через jsDelivr; лицензия MIT сохранена в `vendor/bootstrap/LICENSE`. Ссылки на необязательные source maps удалены. `custom.css` подключён после библиотеки. HTML отформатирован для чтения.

Структура:

- `index.html` — главная с сеткой;
- `catalog.html` — карточки и быстрые заявки;
- `product.html` — описания, таблицы и accordion;
- `order.html` — форма заявки;
- `contacts.html` — дополнительная страница;
- `css/custom.css` — небольшие собственные дополнения;
- `js/main.js` — проверка форм и передача товара;
- `images/` — собственные SVG;
- `vendor/bootstrap/` — локальная библиотека и лицензия;
- `tests/check_site.py` — проверка структуры и локальных ссылок.

Самостоятельные дополнения к базовому примеру: страница контактов, три подробных описания вместо одного, передача выбранного товара из карточки в modal и отдельную форму, проверка количества, телефона и согласия, собственные иллюстрации, локальная библиотека. Наличие этих дополнений не гарантирует оценку: результат нужно уметь объяснить преподавателю.

Для защиты №11: показать локальное подключение без CDN, обязательные компоненты, порядок CSS, обработчик `submit`, работу `checkValidity()` и различие `data-bs-*` и собственного JavaScript. Показать проверку пяти страниц и историю практических №9–11.
